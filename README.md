# СВОЯ BARLEMICA — сокращённая игра

Откройте `index.html` в браузере. Для игры без интернета сохраните всю папку проекта вместе с `assets/`.

Три поля по четыре категории и четыре вопроса. Во всех темах одного раунда одинаковая шкала. В первом раунде — 100, 200, 300 и 400 очков, во втором — 200, 400, 600 и 800, в третьем — 300, 600, 900 и 1200. Правильный ответ прибавляет номинал, ошибка вычитает его, пас оставляет счёт прежним. Перехват разыгрывается за половину номинала. В «Сиропе в мешке» команда передаёт вопрос сопернику за полный номинал.

В конце третьего раунда нажмите «К финалу». Введите ставки от 0 до текущего положительного счёта команды. После фиксации ставок появится вопрос. Введите ответ каждой команды. Сайт сравнит ответы с правильным числом 297 по абсолютной разнице. Победители получают свои ставки, остальные теряют свои. При одинаковой минимальной разнице победа общая. Итоги финала и таблица по очкам отображаются отдельно.

Сокращённая игра сохраняется отдельно. На стартовом экране можно перенести счёт, имена и отметки сыгранных вопросов из прежней игры. Старое сохранение доступно для экспорта.
